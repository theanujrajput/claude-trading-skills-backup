# OpenAlgo Integration Guide

This guide describes how to connect **Claude Trading Skills** with [OpenAlgo](https://openalgo.in) for trade execution, position tracking, and multi-broker support.

---

## 1. Overview

While `claude-trading-skills` focuses on market regime analysis, risk gates, position sizing, and trade journaling, OpenAlgo serves as the execution layer across 35+ supported brokers (Zerodha, Angel One, Upstox, Fyers, Finvasia, Delta Exchange, etc.).

The integration provides:
- **Discipline & Risk Safeguards:** Ensures trade plans pass risk and position sizing limits before routing to OpenAlgo.
- **Plan-to-Order Conversion:** Translates trade plans (entries, worst-case fills, stop losses, and profit targets) into OpenAlgo `placesmartorder` payloads.
- **Portfolio Synchronization:** Fetches demat holdings and active intraday/F&O positions into standard markdown reports.
- **Explicit Confirmation Gates:** Requires explicit manual confirmation (`--confirm`) to prevent unauthorized auto-trading.

---

## 2. Configuration

Set the environment variables in your terminal or shell profile (`~/.zshrc`):

```bash
# OpenAlgo API key generated from your OpenAlgo dashboard (Profile -> API Keys)
export OPENALGO_API_KEY="your_api_key_here"

# OpenAlgo Host URL (default is http://127.0.0.1:5000)
# Note: On macOS, port 5000 is used by AirPlay Receiver, so you might run OpenAlgo on 5001:
export OPENALGO_HOST="http://127.0.0.1:5000"
```

## 3. Using the OpenAlgo Bridge CLI

The bridge is located at `scripts/openalgo_bridge.py`.

### A. Test Connection & Check Margins
Verify connection to your OpenAlgo instance and connected broker:

```bash
uv run python scripts/openalgo_bridge.py check-connection
```

### B. Fetch Holdings & Positions
Retrieve live portfolio holdings and intraday positions in Markdown:

```bash
uv run python scripts/openalgo_bridge.py portfolio --format markdown
```

Save to a report file:

```bash
uv run python scripts/openalgo_bridge.py portfolio --format markdown --output reports/portfolio_openalgo.md
```

### C. Convert a Trade Plan to OpenAlgo SmartOrder
Take a plan generated by `breakout-trade-planner` or `position-sizer` and convert it into an OpenAlgo order payload:

```bash
uv run python scripts/openalgo_bridge.py convert-plan \
  --plan reports/sample_plan.json \
  --exchange NSE \
  --product CNC
```

### D. Place an Order (Guarded)
Preview the order without submitting (dry-run):

```bash
uv run python scripts/openalgo_bridge.py place-order \
  --symbol INFY \
  --action BUY \
  --exchange NSE \
  --product CNC \
  --qty 10 \
  --price 1550.0 \
  --stoploss 1510.0 \
  --target 1630.0
```

Submit with explicit confirmation:

```bash
uv run python scripts/openalgo_bridge.py place-order \
  --symbol INFY \
  --action BUY \
  --exchange NSE \
  --product CNC \
  --qty 10 \
  --price 1550.0 \
  --stoploss 1510.0 \
  --target 1630.0 \
  --confirm
```

## 4. Claude Desktop MCP Setup (Optional)

To let Claude interact with OpenAlgo directly via tools:

Add to your `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "openalgo": {
      "command": "/path/to/claude-trading-skills/.venv/bin/python3",
      "args": [
        "/path/to/openalgo/mcp/mcpserver.py"
      ],
      "env": {
        "OPENALGO_API_KEY": "your_openalgo_api_key",
        "OPENALGO_HOST": "http://127.0.0.1:5000"
      }
    }
  }
}
```
